# UX 개선 구현 계획

- 작성일: 2026-09-23
- 승인 범위: 사용자의 “개선 우선 순위에 따라서 구현 진행” 요청
- 대상: 한국 중·고등학생용 외계행성 신호 수사대
- 기준 자료: work/elementary-webapp-ux-audit.md 및 work/elementary-webapp-ux-language-audit.md
- 구현 뒤 커밋·푸시·배포·HVC 등록은 이 요청에 포함되지 않습니다.

## 우선순위와 변경 범위

### P1 — 핵심 추론 경로

1. 미션별 첫 행동을 다르게 안내해 미션 3의 단일 감소 과제와 반복 신호 공통 문구의 충돌을 없앱니다.
2. 예측 전에 깊이·주기 정답에 가까운 값이 표시되지 않게 합니다. 쉬운 예시와 식은 예측 저장 뒤에 제공합니다.
3. 초기화 후 숫자 입력, 슬라이더, 곡선과 지표가 같은 후보 상태를 표시하게 합니다.
4. 후보 비교는 동일한 현재 관측 자료로 재계산합니다. 저장 당시 적합도와 자료점 수도 함께 표시해 이전 결과의 맥락을 보존합니다.

### P2 — 막힘·읽기 부담·회복

5. 후보 저장 동작에 맞게 버튼명을 고치고 성공 피드백을 표시합니다.
6. 미션 카드의 시각자료 높이를 줄이고, 실제 CSS 크기에 맞춰 그래프 글자와 축을 그려 모바일에서도 읽을 수 있게 합니다.
7. 좁은 화면의 후보 비교표는 한 후보씩 읽는 반응형 카드로 보여 가로 스크롤을 없앱니다.
8. 보고서에서 결론 입력을 증거 다음에 배치하고, 상상도 갤러리는 접힌 참고 영역으로 옮깁니다.
9. 예측 입력 초안을 브라우저 sessionStorage에 보존해 새로고침 뒤 복구합니다. 저장소에는 예측 초안 외 개인정보를 넣지 않으며, 다른 미션을 고르면 해당 예측을 비웁니다.
10. 학생 화면의 VoiceOver QA 메모, P0/P1, 내부 mission ID 표기를 제거하고 미션 제목을 사용합니다.
11. 미션 그래프에 축·자료 종류를 나타내는 이름을 제공하고 텍스트 설명을 붙입니다. VoiceOver 검증은 제외합니다.
12. 빈 예측 저장을 막고, 다른 단계로 이동하려 하면 관측 단계로 돌아가 예측을 저장하도록 안내합니다.

## 구현 순서와 파일

1. src/data/missions.ts, src/views/observe.ts: 미션별 안내, 선행 수치 노출 제거, 입력 검증과 진행 게이트, 임시 초안 복구, 그래프 접근성 이름, 카드 밀도.
2. src/state.ts, src/views/context.ts: 미션별 sessionStorage 초안 읽기·저장·초기화와 상태 동기화.
3. src/main.ts: 예측 전 다음 단계 이동을 막고 learner-facing QA 메모 제거.
4. src/views/fit.ts, src/views/decide.ts: 모든 입력의 초기화 동기화, 후보 저장 피드백, 동일 현재자료 기준 후보 재계산 및 저장 당시 지표/자료 수 표기, 학생용 라벨과 보고 요약 제목.
5. src/style.css, src/views/curve.ts: 반응형 비교표와 축 글자, 미션 카드·보고서 갤러리 밀도 개선.
6. 앱 업데이트 내역에 2026-09-23 날짜와 학습 흐름 개선 요약을 추가합니다.

## 완료 기준

- 미션 1·2·3은 선택 직후 각자 다른 학습 행동이 드러납니다.
- 예측 저장 전에는 미션의 정답 수치 예시가 나타나지 않으며, 빈 입력은 오류 안내를 받고 다음 단계로 진행되지 않습니다.
- 저장한 예측은 같은 탭의 새로고침 뒤에도 돌아오고, 미션을 바꾸면 이전 미션의 예측이 섞이지 않습니다.
- 초기값으로 버튼 뒤 네 후보 입력·곡선·지표가 일치합니다.
- 저장된 후보의 비교 수치가 모든 후보에 대해 현재 같은 관측 집합으로 계산되며, 저장 당시 수치와 자료점 수도 과거 기록으로 표시됩니다.
- 좁은 화면의 비교 결과는 전체 항목을 가로 스크롤 없이 확인할 수 있습니다.
- 보고서 결론 양식이 긴 갤러리보다 먼저 나오며, 갤러리는 필요할 때 펼칠 수 있습니다.
- learner-facing 화면에서 개발 단계·내부 ID·VoiceOver QA 제외 메모가 사라집니다. 앱의 업데이트 내역에는 실제 개선 날짜가 기록됩니다.
- 현재 단계·예측 오류가 눈에 보이고 키보드·터치 가능한 기본 버튼 구조를 유지합니다.

## 작업 경계

- 기존 프로젝트 스택과 앱 구조를 유지합니다. 별도 시뮬레이션, 새 패키지, 이미지 생성은 추가하지 않습니다.
- 파일은 500줄 미만으로 유지합니다.
- 이번 요청은 구현까지입니다. 별도 요청 없이 커밋, 푸시, 배포, HVC 등록은 하지 않습니다.
- 자동 테스트·빌드 및 브라우저 회귀 검증은 요청되지 않았으므로 실행하지 않습니다. 변경 내용은 코드 리뷰로 확인하고, 미실행 범위를 결과에 명시합니다.
