# 중·고등학생 UX 감사 계획

- 일자: 2026-09-23
- 모드: audit-only
- 대상: 한국 중·고등학생, 교사 주도 30분 지구과학·물리·통계 활동
- 질문: 학생이 별빛 감소 자료를 근거로 행성 후보 여부를 판단하고, 추가 관측이 필요한 이유를 설명할 수 있는가?
- 범위: 첫 화면부터 미션 선택, 예측, 후보 조정, 비교, 관측 일정, 결론 기록까지의 실제 브라우저 흐름. 학년별 언어·조작·화면 밀도, 키보드, 모바일 반응형, 핵심 시뮬레이션 동작을 살핍니다.
- 제외: 소스 코드·문구·자산 수정, 이미지 생성, 설치, 배포, 학생 자료 수집, VoiceOver 검증.

## 관점

- 중학생 관점: 그래프에서 반복 여부와 감소 깊이를 읽고, 다음 행동과 피드백을 쉬운 말로 따라갈 수 있는지 봅니다.
- 고등학생 관점: 변수·단위·잔차·적합도·불확실성 설명이 분석에 도움이 되는지, 서로 다른 자료량의 결과가 구분되는지 봅니다.
- 두 관점 모두 실제 학생 인터뷰가 아니라 화면과 흐름에 대한 모의 학습자 관점입니다. 공식 교육과정 매핑이나 실제 학습 효과를 판정하지 않습니다.

## 점검 순서

1. Stage 0 준비 상태와 프로젝트 설계 기준을 확인합니다.
2. 1280×900에서 새로 시작해 결론 저장까지 진행하며 실제 문구, 상태 변화, 오류 회복을 기록합니다.
3. 같은 주요 경로를 375×812 및 320×800에서 확인하고 가로 넘침, 그래프 글자, 핵심 입력 위치와 표의 조작 부담을 살핍니다.
4. 키보드 포커스·슬라이더 조작·초기화·후보 저장·추가 관측·기록 저장과 새로고침을 확인합니다.
5. 실행 가능한 UI/UX 경로 하나와 학생용 문구 감사, 기존 시뮬레이션의 필요성·상태 전이를 통합합니다.

## 수용 기준

100점 게이트를 사용하되 점수는 비교 보조 지표로만 씁니다. P0/P1이 남으면 총점과 관계없이 fail입니다. 중·고등학생 관점의 권장 문구는 개선 후보로만 제시하고, 교과 정확성이 달라질 수 있는 용어 풀이는 human-review로 표시합니다. VoiceOver는 범위에서 제외합니다.

## 예상 산출물

- 실제 흐름의 이슈 장부와 우선순위
- 언어 감사 장부와 학년대별 문구 제안
- 추가 시뮬레이션 결정 및 현재 시뮬레이션 점검 기록
- 점수·수용 게이트·미실행 범위를 담은 최종 보고서
