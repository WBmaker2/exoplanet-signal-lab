# 기존 후보 모형 조작 브라우저 테스트 기록

- 대상: 기존 후보 모형·궤도/겹침 시각화
- 모드: audit-only, 앱 변경 없음
- 미션: mission 1, 설계 데이터 seed 1101
- 환경: 로컬 Vite 미리보기, 375×812 및 비교 확인용 320×800·1280×900
- 기록 유형: 상호작용 관찰. 자동화 테스트나 모델 수치 검증이 아닙니다.

## 실행 기록

| 순서 | 조작 | 관찰 결과 | 판정 |
| --- | --- | --- | --- |
| 1 | 시작 버튼을 누르고 미션 1 선택 | 관측 화면에 그래프·선택 카드·예측 입력이 표시됨 | 확인됨 |
| 2 | 예측에 1.4% 감소 입력 후 저장 | 화면에 저장됐다고 표시됨. 입력 전에 이미 비슷한 깊이·주기가 안내됨 | 작동하지만 예측 독립성은 부족 |
| 3 | 후보 탭에서 슬라이더를 ArrowRight로 조작 | k가 0.1에서 0.102로 바뀌고 χ²가 237.6에서 230.9로 갱신됨 | 확인됨 |
| 4 | 숫자 입력을 0.12로 변경 | χ² 195.2, 모형 밝기 0.9856으로 갱신됨 | 확인됨 |
| 5 | 후보 저장 → 비교로 선택 | 후보가 저장되지만 화면은 후보 탭에 남고 별도 성공 피드백이 없음 | 문구/전이 불일치 |
| 6 | 비교 탭을 직접 엶 | 저장된 후보를 확인 가능. 모바일에서는 내부 가로 스크롤 필요 | 부분 확인 |
| 7 | 일정에서 21.0–22.4일 창 선택 | 남은 예산 3→2, 후속 관측점 8개 추가 및 상태 안내 | 확인됨 |
| 8 | 후보 탭 확인 | 현재 곡선은 195개 자료점, χ² 199.9로 갱신됨 | 확인됨 |
| 9 | 비교 탭 확인 | 기존 저장 행은 χ² 195.2로 유지되고 자료점 개수·저장 시점 표시는 없음 | 학습상 혼란 |
| 10 | k=0.12에서 초기값으로 선택 | 그래프는 초기 모형을 반영하나 슬라이더·숫자 입력은 0.12를 유지 | 실패 |

## 반응형·기본 상호작용

- 1280×900: 페이지 가로 넘침 없음. 세 개의 미션 카드가 긴 세로 목록이며 예측 상자는 전체 콘텐츠 아래쪽에 놓임.
- 375×812: 페이지 가로 넘침 없음. 선택 카드들이 화면을 길게 사용하며 예측 영역이 약 y=1556px에 도달.
- 320×800: 페이지 가로 넘침 없음. 곡선 캔버스 축 글자는 폭 축소로 약 3.7–4.6 CSS px 수준. 비교표는 약 431px 너비로 자체 가로 스크롤.
- 키보드: 첫 Tab은 건너뛰기 링크, 두 번째 Tab은 관측 단계 버튼을 보이는 포커스와 함께 선택. 슬라이더 방향키 조작 가능.
- 브라우저 로그: error/warn 없음.

## 미실행

- 실제 터치 하드웨어, 실행 중 reduced-motion 전환, 2D fallback 강제 동작, 학생 인터뷰, 과학 계산의 독립 검증, 자동화된 빌드 및 테스트.
- VoiceOver 검증은 사용자 범위 지시에 따라 제외.
