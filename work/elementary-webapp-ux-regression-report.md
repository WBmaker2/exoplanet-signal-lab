| 후보 조절·비교 | 숫자 입력과 슬라이더가 같은 값을 가리킵니다. 2개 후보를 저장한 뒤 추가 관측 10점이 들어오자 저장 당시 166점 기록은 유지되고 현재 적합도는 두 후보 모두 같은 176점으로 다시 계산됩니다. | 통과 |

| 모바일 후보 비교 | 320px·375px에서 표 대신 비교 카드 2개가 나타나고, 1280px에서는 비교 표가 나타납니다. | 통과 |

320×800에서 관측 전 예측 입력은 이전 점검의 약 y=1,889px에서 이번에는 미션에 따라 약 y=819–842px로 이동했습니다. 주요 3개 폭에서 `scrollWidth === clientWidth`였습니다. 320px에서 편집 입력 글자는 16px입니다.

## 패널 관점

- 중학생 관점: 먼저 선택 미션을 읽고 그래프를 본 뒤 예측을 기록할 수 있습니다. 다른 단계부터 누르면 저장이 필요하다는 안내가 나오고, 빈 입력을 고르면 입력 칸으로 돌아옵니다. 미션을 바꾸면 이전 예측이 섞이지 않습니다.
- 고등학생 관점: 후보를 저장한 시점의 점수·자료점 수와 현재 자료 기준 점수를 따로 읽을 수 있습니다. 후속 자료가 추가된 뒤 모든 후보가 같은 176개 자료로 비교되고, 작은 잔차가 행성의 증명은 아니라는 안내가 남습니다.
- 위 내용은 행동 기반 simulated learner panel 기록입니다. 실제 학습자 의견으로 일반화하지 않았습니다.

## 검증 결과

- `npm test`: 1개 파일, 11개 테스트 통과.
- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
- `git diff --check`: 통과.
- 브라우저 경로: 시작 → 미션 전환 → 저장 전 이동 차단 → 예측 저장 → 후보 2개 조절·저장 → 후속 관측 → 현재 자료 기준 비교 → 근거·한계가 포함된 보고 저장.
- 반응형: 320×800, 375×812, 1280×900. 모바일 비교 카드와 데스크톱 표를 각각 확인했습니다.
- 키보드: 첫 포커스가 건너뛰기 링크이고, 단계 버튼·업데이트 내역 다음에 시작 버튼이 이어집니다.
- 동작 감소 설정: `prefers-reduced-motion: reduce`에서 시작 버튼 애니메이션은 `none`, 정적 테두리는 유지됩니다.
- 브라우저 이벤트 191개 중 JavaScript 예외, 콘솔 오류, 실패 요청은 0개였습니다.
- 상단의 `업데이트 내역`에서 2026-09-23 변경 내용을 확인했습니다.
