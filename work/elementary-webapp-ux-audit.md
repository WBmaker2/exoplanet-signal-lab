## P0–P3 이슈 장부

### EDU-UX-001 — P1: 미션별 과제와 공통 지시가 충돌함

- 상태: open
- 경로/상태: 시작 → 관측 → 미션 3 선택
- 관찰: 상단 지시는 세 곡선 중 반복 감소 후보를 고르라고 합니다. 미션 3은 관측 구간에 감소가 한 번뿐이라고 설명하며 “한 번 어두워졌다고 행성이 있을까요?”라고 묻습니다. 하나의 공통 지시를 따르려면 미션 설명을 무시하거나 과제를 추측해야 합니다.
- 근거: src/views/observe.ts 19–22, src/data/missions.ts 80–83.
- 학습자 영향: 중학생은 반복 감소를 반드시 찾아야 하는 것으로 받아들일 수 있습니다. 고등학생도 미션 고유 질문과 상위 지시 중 무엇을 평가 기준으로 삼는지 알기 어렵습니다.
- 원인 가설: 미션별 목표를 별도로 두었지만 상단 지시는 단일 미션 전용 문구로 고정되어 있습니다.
- 개선 제안: 상단 지시는 공통 목적만 설명하고, 각 미션 카드 선택 후 해당 미션에서 찾을 신호와 다음 행동을 따로 안내합니다.
- 확인 시나리오: 미션 1·2·3을 각각 선택해 첫 행동을 한 문장으로 재진술할 수 있는지, 특히 미션 3에서 반복 통과가 없어도 다음 관측 계획으로 이어지는지 확인합니다.

### EDU-UX-002 — P1: 예측 입력 전에 답에 가까운 수치를 공개함

- 상태: open
- 경로/상태: 시작 → 관측 미션 1 → 예측 기록 전
- 관찰: 미션 설명에 “깊이 약 1.4%, 4일 남짓 간격”이 먼저 나오며 예측 입력 영역도 이상적 감소식과 이 미션의 설계 예시 1.44%를 표시합니다. 예측을 먼저 남기는 학습 목표와 같은 화면에서 답의 크기·간격을 알려 줍니다.
- 근거: src/data/missions.ts 45–48, src/views/observe.ts 69–73, 96–100.
- 학습자 영향: 학생은 그래프에서 예측하기보다 화면에 나온 값을 옮겨 적을 수 있습니다.
- 원인 가설: 공통 관계 설명과 해당 미션의 정답에 가까운 수치 예시가 예측 전 화면에 함께 배치되었습니다.
- 개선 제안: 입력 전에는 추론에 필요한 단위와 관찰 방법만 제공하고, 예측을 저장한 뒤 관계식·기준 수치를 열어 볼 수 있게 순서를 바꿉니다. 예상 답을 미션 요약에도 먼저 적지 않습니다.
- 확인 시나리오: 새 세션에서 예측을 입력하기 전에는 깊이·주기의 목표 수치가 보이지 않고, 입력 저장 뒤에는 그 수치와 모형을 비교할 수 있는지 확인합니다.

### EDU-UX-003 — P1: 초기화 뒤 조절값과 실제 모형이 다르게 표시됨

- 상태: open
- 경로/상태: 후보 탭에서 반지름 비를 0.12로 조절 → 초기값으로 선택
- 관찰: 곡선과 밝기 값은 초기 상태로 바뀌지만 슬라이더·숫자 입력에는 0.12가 남습니다. 학생에게는 입력값과 그래프 중 어느 쪽이 현재 모형인지 판단할 근거가 없습니다.
- 근거: src/views/fit.ts 82–108, 139–147, 219–242. 브라우저에서 초기화 후 그래프 밝기 0.99000으로 바뀌고 입력은 0.12로 남는 것을 확인했습니다.
- 학습자 영향: 반지름 비와 밝기 감소의 관계를 잘못 연결하거나 실험을 포기할 수 있습니다.
- 원인 가설: 초기화는 공유 상태를 갱신하지만 구독 새로고침은 그래프와 지표만 다시 계산하고 입력 요소 값을 동기화하지 않습니다.
- 개선 제안: 상태가 바뀔 때 숫자 입력과 슬라이더를 같은 후보 값으로 함께 갱신하고, 초기화 결과를 짧게 알립니다.
- 확인 시나리오: 네 변수를 바꾼 뒤 초기화하고 화면의 모든 값·곡선·요약이 같은 초기 후보를 가리키는지 확인합니다. 숫자 입력과 키보드 슬라이더에서도 반복합니다.

### EDU-UX-004 — P1: 후속 자료를 받은 뒤 비교표가 저장 당시 적합도만 보여 줌

- 상태: open
- 경로/상태: 후보 저장 → 관측 일정 선택 → 후보·비교로 돌아가기
- 관찰: 일정 선택 후 후보 화면은 195개 자료점, 적합도 199.9를 보여 줍니다. 비교표의 기존 후보 행은 187개 자료점에서 저장한 195.2를 그대로 보여 주며 자료 수나 계산 시점을 표기하지 않습니다. 서로 다른 자료 조건의 수치라는 설명이 없습니다.
- 근거: src/views/fit.ts 130–137, 236–242; src/views/decide.ts 95–105, 173–188. 브라우저에서 기존 저장 후보와 후속 관측 뒤의 현재 자료 지표가 달라지는 것을 확인했습니다.
- 학습자 영향: 중·고등학생이 새 증거가 후보 간 차이를 바꾸었는지 오해할 수 있습니다.
- 원인 가설: 저장된 적합도는 시점별 결과로 유지되지만 비교표에는 자료 버전·자료점 수가 함께 기록되지 않습니다.
- 개선 제안: 비교표에 각 결과의 자료점 수와 갱신 시점을 보이고, 후속 자료에 대해 같은 후보들을 다시 계산하는 별도 현재 비교를 제공합니다. 저장 당시 결과도 과거 증거 기록으로 구분해 보존합니다.
- 확인 시나리오: 후보 둘을 저장한 뒤 관측 창을 선택하고, 동일한 두 후보가 이전 자료와 후속 자료 각각에서 비교되는지 확인합니다. 자료점 수와 범례로 서로 다른 결과 묶음을 구별할 수 있어야 합니다.

## 확인된 강점

- 첫 화면은 질문 하나와 시작 버튼 하나를 두어 설계 의도에 맞습니다.
- 320, 375, 1280px에서 페이지 가로 넘침은 관찰되지 않았습니다.
- 건너뛰기 링크와 키보드 포커스 표시가 보이고, 슬라이더는 방향키로 조작할 수 있습니다.
- 보고서의 결론 미선택·근거/한계 누락 검증은 회복 가능한 안내를 줍니다.
- 추가 관측 창을 고르면 예산과 확보 자료 수, 반영 완료 상태를 알려 줍니다.
- 합성 자료·상상 삽화·3D 크기 확대의 한계를 구분합니다. 업데이트 내역 패널은 열고 Escape로 닫을 수 있으며 포커스가 버튼으로 돌아옵니다.

- 경로: 시작 → 미션 선택·예측 → 모형 조절·초기화·후보 저장 → 비교 → 후속 관측 → 결론 검증·저장.
- 페이지 수평 넘침은 없음. 비교표 내부 가로 스크롤은 있음.
- 브라우저 error/warn 로그: 없음.
- 키보드 확인: 첫 Tab 건너뛰기 링크, 보이는 포커스, 슬라이더 방향키 조작. VoiceOver 검증은 제외했습니다.
- 미실행: 실제 중·고등학생 이해도 인터뷰, 터치 기기 검증, 실행 중 reduced-motion 에뮬레이션, WebGL 고장 대체 화면 강제 전환, 공식 교과과정·과학 모형 독립 검토, 자동화 테스트·빌드.
