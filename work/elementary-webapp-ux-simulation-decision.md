# 인터랙티브 시뮬레이션 결정 기록

- 일자: 2026-09-23
- 결정: not-needed — 추가 시뮬레이션 제안 없음
- 근거: 앱에는 이미 관측 곡선과 후보 모형, 조절 가능한 주기·반지름 비·기울기·중심 시각, 시간 커서, 3D 궤도, 원 겹침 도식, 수치표가 있습니다. 이 주제에는 새 Canvas/WebGL 엔진을 더하는 것보다 현재 입력과 결과가 일치하도록 고치는 일이 우선입니다.
- 적용 범위: 아래 기록은 기존 모델 조작의 제한된 브라우저 점검입니다. 과학 엔진의 독립 검증은 포함하지 않습니다.

## 기존 상호작용

- 학습 목표: 밝기 감소의 깊이·반복 간격·궤도 기하를 후보 모형과 연결하고, 작은 잔차가 행성 발견의 증거가 아님을 설명합니다.
- 바꿀 수 있는 변수: 주기 P(일), 반지름 비 k, 궤도 기울기 i(°), 통과 중심 시각 t0(일).
- 조작 경로: 네이티브 슬라이더 및 숫자 입력; 슬라이더는 방향키로 조작됨.
- 관찰 결과: 관측·모형 곡선, 잔차 띠, χ²/RMSE, 궤도 장면, 원 겹침 도식, 시간별 수치표.
- 모델 경계: 프로젝트 문서는 구형 균일 밝기 별, 불투명 구형 행성, 원궤도, 단일 행성, 태양과 같은 별의 단순화를 규정합니다. 실제 관측 자료가 아니라 수업용 합성 자료입니다. 이 감사는 그 계산값의 물리 정확성을 독립적으로 검토하지 않았습니다.
- 정적 대체: 후보 그래프는 이미지 역할 이름과 펼침 가능한 수치표가 있습니다. 궤도 장면 옆에 2D 원 겹침 도식이 있습니다. WebGL 실패 강제 시험은 not run입니다.

## 상태 점검 기록

| 항목 | 판정 | 증거 |
| --- | --- | --- |
| 예측 | 부분 확인 | 미션을 고르고 깊이를 기록할 수 있으나 정답에 가까운 수치가 입력 전에 노출됨 |
| 조작 | 확인됨 | 375px 브라우저에서 숫자 입력 및 슬라이더 방향키 조작으로 k를 0.1에서 0.102, 다시 0.12로 변경했고 지표가 갱신됨 |
| 관찰 | 확인됨 | 후보 모형과 밝기 값·잔차·적합 지표가 갱신됨. 일정 선택 뒤 현재 후보 화면에 후속 관측 자료가 반영됨 |
| 설명 | 부분 확인 | 보고서는 근거·대안·한계를 요구하지만 결론은 학생 입력에 의존하고 자동 이해 probe는 하지 않음 |
| 재시도 | 실패 | 초기값 버튼 뒤 그래프는 초기 상태로 돌아오나 슬라이더와 숫자 입력 중 k가 이전 0.12로 표시됨 |
| 비교 | 부분 확인/혼란 | 저장한 후보의 수치는 남지만 후속 관측 자료가 추가된 뒤 같은 후보의 저장 당시 자료점 수와 비교 화면의 현재 자료 조건이 구별되지 않음 |
| pause | N/A | 시간이 자동으로 흘러 상태를 바꾸는 실행이 없습니다. 사용자가 시간 커서를 직접 움직입니다. |
| step | N/A | 순차 시간 시뮬레이션이 자동 재생되지 않으며 연속 커서 조작과 방향키로 원하는 시간을 직접 봅니다. 한 단계씩 재생하는 기능은 이 흐름에 필수라고 판단하지 않았습니다. |
| 결정적 seed/time | 부분 확인 | 설계 문서와 미션 소스는 고정 seed를 사용합니다. 이번 UX 감사에서는 seed 재현성이나 엔진 버전별 수치 동일성을 검증하지 않았습니다. |
| 터치·reduced-motion | not run | 정적 CSS에는 44px 조작과 모션 축소 시 정적 강조가 있으나 실행 기기·모션 설정을 변경해 확인하지 않았습니다. |

## 재현 가능한 결함 시나리오

1. 미션 1을 열고 후보 탭으로 갑니다.
2. 반지름 비 k를 숫자 입력으로 0.12로 설정합니다.
3. 초기값으로 버튼을 누릅니다.
4. 그래프는 초기 모형의 밝기 약 0.99000을 보이지만 슬라이더·숫자 입력은 k=0.12를 계속 표시합니다.
5. 후속 관측 자료를 추가한 후 후보 화면과 비교 화면을 확인합니다. 후보 화면 지표는 195개 자료점 기준으로 바뀌지만 비교표의 기존 저장 지표는 187개 자료점 기준으로 남습니다.

## 조치

현재 앱에는 별도 시뮬레이션을 추가하지 않습니다. 향후 구현 승인 시 상태 값과 모든 입력·그래프·적합 결과의 동기화, 기준선 결과와 후속 자료 결과의 명시적 분리, 같은 변수값으로 다시 비교하는 흐름을 먼저 고칩니다. 변화 후에는 동일한 위 시나리오와 모바일·키보드 경로를 다시 확인해야 합니다.
