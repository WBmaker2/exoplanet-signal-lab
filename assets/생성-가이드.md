# 이미지 자산 생성 가이드 (P0 · 9장)

이 문서는 **image 2.5**(`gemini-2.5-flash-image`)로 미션 배경 3장과 가상 행성 상상도 6장을 직접 생성하기 위한 안내입니다. 생성한 PNG를 `assets/raw/`에 아래 파일명 그대로 저장한 뒤 알려주시면, 제가 압축(WebP)·검수·앱 삽입·자산 기록까지 진행합니다.

## 1. 생성 설정

- 도구: Google AI Studio (웹 UI, 무료 생성 가능 여부는 계정 정책에 따라 다름)
- 모델: **Gemini 2.5 Flash Image** (= image 2.5, nano banana)
  - 목록에 없다면 최신 모델(Nano Banana 2 계열)로 보이는데, 그 경우 **어떤 모델로 만들었는지 알려주세요.** 기록에 `modelUsed`로 정확히 남깁니다(조용히 대체하지 않음).
- 비율: 배너 3장 = `16:9`, 행성 6장 = `1:1`
- 해상도: image 2.5는 1024px급 출력입니다(배너 1024×576, 행성 1024×1024). 카드 삽입 용도로 충분합니다.
- 스타일 일관성(권장): 첫 배경(`mission-1-banner`)을 만든 뒤, 나머지 8장은 그 이미지를 **참조 이미지로 첨부**하고 프롬프트를 붙여넣으세요. 첨부가 어렵다면 그냥 붙여넣어도 되고, 제가 일관성을 검수합니다.

## 2. 저장 규칙

- 위치: 프로젝트 폴더의 `assets/raw/`
- 파일명(정확히):
  - `mission-1-banner.png`
  - `mission-2-banner.png`
  - `mission-3-banner.png`
  - `planet-01-ocean.png`
  - `planet-02-desert.png`
  - `planet-03-ice.png`
  - `planet-04-ringed.png`
  - `planet-05-clouded.png`
  - `planet-06-twotone.png`

## 3. 검수 기준 (생성 직후 스스로 확인)

1. **문자·숫자·기호·워터마크가 없어야** 합니다. 있으면 다시 생성하세요.
2. **사진처럼 보이면 안 됩니다.** 부드러운 교육용 삽화 느낌이어야 합니다(관측 사진으로 오인 방지).
3. 행성 그림에 **크기 비교·눈금·측정 표시가 없어야** 합니다(숨은 정답 단서 방지).
4. 밝기 곡선·그래프는 이 이미지들에 포함하지 않습니다(그래프는 앱이 코드로 그립니다).

## 4. 공통 스타일 문장 (모든 프롬프트 끝에 이미 포함됨)

> 부드러운 교육용 삽화. 실제 관측 사진처럼 보이지 않게, 손으로 그린 듯 단순하고 평면적인 구아슈 느낌. 밝고 차분한 파스텔 색감(따뜻한 종이색 바탕). 문자·숫자·기호·워터마크 없음. 네온·렌즈플레어·SF 장식 없음.

## 6. 생성 후

`assets/raw/`에 저장한 뒤 "이미지 넣었어"라고 알려주세요. 그러면 제가:

1. `tools/compress_assets.py`로 WebP 압축(배너 ≤500KB, 카드 ≤150KB 목표)
2. 스타일 일관성·금지 요소(문자·눈금·사진 느낌) 검수
3. 앱 삽입(관측 탭 미션 카드 배경, 보고 탭 상상도 갤러리)
4. 자산 기록(`assets/assets-manifest.json`) 작성 — id, purpose, promptVersion, modelUsed, referenceIds, semanticLabels, alt, dimensions, licenseNote, reviewStatus
5. 테스트·빌드·기록(`배포-점검-기록.md`) 갱신 후 배포

## 7. 라이선스·비용 메모 (2026-09-18 확인)

- image 2.5 API 가격: 표준 $0.039/장, 배치 $0.0195/장 (9장 ≈ $0.35 / 배치 ≈ $0.18). 무료 API 티어 없음.
- AI Studio 웹 UI에서의 무료 생성 가능 여부는 계정 정책에 따라 다릅니다.
- 생성 이미지에는 SynthID 워터마크가 포함됩니다. 수업용 삽화로 사용하며, 실제 관측 자료로 표기하지 않습니다.
